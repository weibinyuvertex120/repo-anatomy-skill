# Project Analysis

## Core Structure

Use this order when applicable:

1. Conclusion and decision guidance.
2. Verified project identity and current status.
3. Problem solved and capability map.
4. Architecture or content organization.
5. Practical workflows and adoption path.
6. Maintenance, ecosystem, and compatibility.
7. Security, privacy, license, and operational risks.
8. Suitable and unsuitable scenarios.
9. Verification notes and sources.

## Decision-Oriented Conclusion

Answer early:

- What is it?
- What is it genuinely good for?
- What should not be inferred from its marketing or popularity?
- Who should evaluate it next?
- What must be checked before production use?

## Repository Status

When analyzing a repository, verify as relevant:

- Default branch and latest release or commit scope.
- License and archival state.
- Installation and runtime requirements.
- Maintainer guidance and contribution policy.
- Recent activity, without treating activity alone as quality.
- Tests, examples, security guidance, and known limitations.

Attach an exact date to volatile metrics. Prefer qualitative maintenance conclusions over decorative star counts.

## Capability Map

Group capabilities by user workflow, not by README order. For a resource collection, classify entries by the job they help complete. For a software project, map setup, core operation, integration, observability, safety, and maintenance.

## Risk Review

Check:

- License scope and third-party licenses.
- Data handling and external network dependencies.
- Required permissions and execution boundaries.
- Platform or version limitations.
- Maintenance and migration risk.
- Claims that rely on project-authored benchmarks.

## Analysis Failure Patterns

Reject a draft that:

- Equates stars with reliability.
- Treats “free” as commercial-use permission.
- Repeats project descriptions without explaining adoption decisions.
- Lists components without a capability map.
- Omits unsuitable scenarios.
- Uses current metrics without a date.
- Turns absence of evidence into a positive claim.
